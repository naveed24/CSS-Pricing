# CSS Pricing Component

A responsive pricing page built with **HTML and CSS only**, based on the MountBlue pricing component exercise.

## Features

- Mobile-first layout
- Single-column mobile, two-column tablet, and three-column desktop presentation
- CSS-only monthly/annual pricing toggle using `:checked` and `:has()`
- Keyboard-visible focus state on the switch
- Hover states for the toggle and buttons
- Montserrat typography and colors from the provided style guide

## Preview locally

Open `index.html` in a modern browser, or use the VS Code Live Server extension.

## Responsive breakpoints

- Mobile: below 768px
- Tablet: 768px–1023px
- Desktop: 1024px and above

Reference design widths: 375px and 1440px.
